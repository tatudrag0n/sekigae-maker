# 席替えメーカー

席数・列数を自由に変えられる席替えツールです。席はドラッグで入れ替えでき、さらに「コナミコマンド」を入力すると**不正モード**に入り、好きな席に好きな番号を割り当てられます。

## 機能

- **人数・列数の変更**（1〜60人 / 1〜10列）— 設定パネルでいつでも変更できます
- **席替え** — フィッシャー–イェーツ法で偏りなくシャッフル
- **ドラッグで入れ替え** — 席をつかんで別の席へドロップすると番号が入れ替わります（タッチは長押しでドラッグ開始）
- **不正モード** — コナミコマンドで ON/OFF。席をタップ（または Enter）して任意の番号を入力できます。重複や範囲外の番号、空席も作れます
- **自動保存** — 配置は `localStorage` に保存され、再読み込みしても残ります

## コナミコマンド

タイトル画面などはありません。ページ上で次の順にキーを入力してください。

```
↑ ↑ ↓ ↓ ← → ← → B A
```

`不正モード` バッジが出たら成功です。もう一度入力すると解除されます（バッジをクリックしても解除できます）。

## 使い方

1. 「人数」「列数」を決める
2. 「席替えする」を押す
3. 気になる席はドラッグで入れ替え
4. 必要ならコナミコマンド → 席をタップして番号を指定

## ローカルで動かす

ビルド不要の静的サイトです。

```bash
python3 -m http.server 8000 --directory docs
# http://localhost:8000
```

## GitHub Pages で公開する

このリポジトリの GitHub Pages は `main` ブランチの `docs/` を公開元にしています。

- 公開 URL: https://tatudrag0n.github.io/sekigae-maker/
- `main` に push すると自動で再ビルドされます

別のリポジトリで同じ構成にする場合は、**Settings → Pages → Source** を **Deploy from a branch** にして、ブランチ `main`・フォルダ `/docs` を選んでください。
